# UA 与 OS 不一致：怎么判断、怎么处理

> 一句话：一次 eapi 请求里，**UA、cookie 的 `os/appver/osver`、eapi header 对象**这三处必须指向同一个平台，
> 否则 `-460`；不自洽还会连带把风控等级推高。
> 这篇只讲判断方法与处理原则，**不给代码**；具体取值在 `yidun-api.js` 顶部（一个常量 + 一个对象）。

## 一、三个地方会互相打架

一次 eapi 请求，网易云会同时看到三处身份信息：

| 位置 | 内容 | 谁写的 |
|---|---|---|
| HTTP 头 `User-Agent` | 客户端标识，如 `…NeteaseMusicDesktop/3.1.29.205117` 或 `…Chrome/124 Safari/537.36` | 调用方传，或 SDK 按 `chooseUserAgent()` 兜底 |
| Cookie 里的 `os` / `appver` / `osver` | 设备平台与版本，如 `os=pc; appver=3.1.17.204416; osver=Microsoft-Windows-10-…` | cookie 串，或 SDK 的 `processCookieObject()` 兜底补 |
| eapi 的 header 对象 | 会把上面几个字段再序列化一遍，塞进 `Cookie` 头 | SDK 内部组装 |

**只要这三处指向的不是同一个平台/版本，就会出问题。** 典型矛盾：

- UA 说 iPhone（`chooseUserAgent('api','iphone')` 的兜底），cookie 的 `os` 却是 `pc`；
- UA 说 Mac Chrome（weapi 的默认），cookie 却是 Windows 的 `osver`；
- 上一轮是 PC 客户端，下一轮换了 sid 又变成浏览器 —— 同一账号在短时间内"换设备"。

## 二、表现不一样，怎么区分

| 现象 | 多半是哪一处不一致 |
|---|---|
| `-460`（网络环境异常） | UA 与 cookie 的 `os` 明显冲突（最典型：iPhone UA + `os=pc`） |
| `8821` / `8810` | 身份本身自洽，但**环境**被判可疑（出口 IP、设备指纹历史、频繁切换设备） |
| `-462` | 设备凭证（`NMTID`）是伪造的，或本次请求没带设备凭证 |

> `8821` / `8810` 不一定是 UA/os 的锅，先把 `-460` 排掉，再怀疑环境。

## 三、判断顺序（按这个顺序查，别跳）

1. **看请求头 UA**：抓一次实际发出去的请求，确认 UA 里的客户端标识。
2. **看 Cookie 里的 `os` / `appver` / `osver`**：与 UA 比对平台（pc/osx/iphone/android）是否一致。
3. **看 appver 与 UA 里的版本号**：`NeteaseMusicDesktop/3.1.29.x` 就要配 `appver=3.1.29.x` 这一档，
   拿 3.1.17 去配 3.1.29 的 UA 属于"版本对不上"，风控也认得出。
4. **看这个 sid 之前用过什么身份**：同一个会话中途换身份，比一开始就用错更容易被拦。
5. **最后才怀疑出口 IP**：代理/机房 IP 会稳定叠加 `8810`，与 UA 无关。

## 四、处理原则

1. **三处取同一个平台**：定下"PC 客户端"就 UA、`os=pc`、`appver/osver` 全部按 PC 客户端写；
   定下"Mac 浏览器"就 `os=osx` 配 Mac UA。不要混搭。
2. **版本对齐**：UA 里的客户端版本与 `appver` 保持同一档，不要一个 Chrome 一个客户端版本。
3. **一个会话一个身份**：同一 `sid` 内不要换 UA/os；要换就换 `sid`，当作新设备。
4. **身份要稳定**：`deviceId`、`_ntes_nuid`、`WNMCID` 这些一旦定了就别每次重新随机，
   否则在服务端看就是"同一账号不断换新设备"。
5. **不要靠"多试几次"解决**：身份不一致是确定性错误，重试只会把风控等级压深。

## 五、常见误判

| 误判 | 实际情况 |
|---|---|
| "补了 `os=pc` 还是 8821，所以 os 无关" | 8821 是环境风控，本来就不是 os 能解的；`os` 只影响 `-460` |
| "UA 随便给一个浏览器就行" | 浏览器 UA 会走 weapi 那套判定；密码登录要的是客户端 UA |
| "身份换着试，总能试出一个能过的" | 每次换都是一次"设备变更"，只会更糟 |
| "只要 header 里字段齐了就行" | 关键是**三处自洽**，字段齐但不自洽照样 -460 |
